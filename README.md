Intelligent Electrical Grid Fault Detection & Protection Simulator

GridGuard is an electrical distribution-grid simulation and protection system designed to demonstrate how intelligent monitoring can be used to detect abnormal operating conditions and automatically isolate faults.
Project Vision

The long-term goal of GridGuard is to explore how simulation, intelligent algorithms, and software engineering can be combined to create smarter and more resilient electrical power systems.

Simulate. Detect. Decide. Protect.
